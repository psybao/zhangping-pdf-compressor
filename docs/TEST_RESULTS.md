# 已执行的测试

测试日期：2026-11-18。测试 PDF 为本项目生成的确定性样本，不包含用户真实文件。

|范围|结果|
|---|---|
|Windows 实际压缩矩阵|35 个品质/目标体积用例通过|
|Windows 快速预估|49 个元数据预估用例通过，确认不执行完整压缩、不保存候选 PDF、不全文件哈希|
|Windows 2 MB 上限|文字、扫描和混合 PDF 的预估、范围及实际输出均不超上限；未达标与异常缓存拒绝发布|
|Windows 界面|导入不自动预估、手动预览、参数失效、模式禁用、四步引导、源/结果打开路径、缩放测试通过|
|Windows 打包|独立 EXE、便携版和隔离安装后的程序实际启动；双图片进程的独立 EXE 完成 4 页 PDF|
|Android 实际压缩矩阵|35 个用例，包含文字提取一致、页数/页面框与 PdfRenderer 打开渲染|
|Android 快速预估|49 个预估与目标上限用例，通过且不生成候选 PDF|
|Android 界面与引导|实际点击四步引导、关闭状态持久化、帮助重开、手动预览、2 MB 批处理通过|
|Android 打开按钮|实际按钮点击并截获 ACTION_VIEW Intent，源文件在压缩前后 URI 不变，结果按钮使用输出 URI|
|文件安全|加密/空/损坏/签名字段拒绝，唯一副本、覆盖、原件变化、取消、失败恢复、输出体积与完整性验证|

测试系统：Windows 11 x64，版本 22631；Android 15/API35 x86_64 模拟器。APK 使用纯托管 PDF 引擎，兼容 ARM64，但 ARM64 真机安装曾被设备拒绝，未完成实机测试。Windows 10、Android 8/12/13/14/16 不宣称已实测。

文件占用与磁盘空间不足的部分恢复测试采用故障注入，没有对用户磁盘制造实际满盘。测试通过不代表任意复杂 PDF 在所有阅读器中都已做完整视觉等价验证。

原始结构化结果见同目录 JSON。性能测量口径、前后耗时与限制见 [WINDOWS_PERFORMANCE_REPORT.md](WINDOWS_PERFORMANCE_REPORT.md)。
